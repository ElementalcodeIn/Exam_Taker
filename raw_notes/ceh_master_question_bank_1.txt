1. During an internal assessment, you discover an upstream device is dropping your probes inconsistently. You want to map which ports are subject to filtering rules and also determine whether the device performs stateful inspection—without attempting to establish full TCP sessions. Which network scanning technique is most appropriate?
A. TCP SYN (half-open) scan
B. TCP Connect() scan
C. TCP ACK scan
D. UDP scan
Correct Answer: C Explanation: A TCP ACK scan is specifically used to infer firewall rule behavior and statefulness because it sends packets with only the ACK flag set and classifies ports as “unfiltered” when an RST is returned and “filtered” when no response or certain ICMP messages are received; this behavior reveals whether a device is performing simple stateless ACL filtering or stateful inspection tracking connection state (e.g., nmap -sA), which aligns with CEHv13’s focus on differentiating firewall behaviors. Option A (TCP SYN scan, nmap -sS) is excellent for discovering open/closed/filtered port states with lower logging than full connect scans, but it attempts to identify service receptiveness by eliciting SYN/ACKs and is not optimal for determining stateful vs. stateless filtering. Option B (TCP Connect(), nmap -sT) fully completes the three-way handshake via the OS socket API, resulting in more obvious logs and is intended for service reachability rather than firewall state analysis. Option D (UDP scan, nmap -sU) is appropriate for enumerating UDP services and interpreting ICMP Type 3 codes and timeouts, but does not diagnose TCP firewall statefulness; UDP behavior through filters is markedly different and often ambiguous (“open|filtered”), making it unsuitable for the stated goal.

2. Your e-commerce /24 is hit by a “carpet bombing” DDoS: tens of millions of PPS of UDP/80 across many IPs in the /24, not just the VIP. You coordinate with your ISP to mitigate without blackholing the whole prefix. Which provider-side technique is MOST appropriate to surgically reduce impact?
A. Enable uRPF loose mode on your edge to drop spoofed egress packets leaving your network
B. Use BGP Flowspec to push rate limits/filters for UDP/80 toward the provider’s edge for your /24
C. Increase TTL on your servers’ responses to survive congestion
D. Enable Rapid-PVST+ on access switches to prioritize web VLANs
Correct Answer: B Explanation: BGP Flowspec allows the upstream provider to install granular, near-real-time filtering/rate-limiting rules keyed on fields like dst-prefix, protocol, and ports, ideal for diffusing high-PPS “carpet bombing” across a prefix while preserving other traffic; it is widely used by carriers and scrubbing centers. Option A (uRPF on your edge) prevents your network from being a source of spoofed traffic but does not mitigate inbound floods to you; widespread uRPF/BCP 38 is a global preventative, not an immediate defense for traffic you’re receiving. Option C (TTL) has no bearing on congestion or inbound flood volume. Option D (spanning tree tweaks) is unrelated to provider-edge DDoS mitigation.

3. A red team floods an event source to trigger thousands of parallel function invocations, exhausting account concurrency and degrading critical workloads. Which control MOST directly caps the number of simultaneous executions for a specific function to contain this impact?
A. Deploy the function across multiple regions with active-active failover
B. Increase memory size so each invocation finishes faster
C. Configure reserved concurrency on the function to set an upper bound
D. Enable provisioned concurrency equal to expected peak traffic
Correct Answer: C Explanation: C is correct because reserved concurrency enforces a hard maximum on parallel executions for that function, containing blast radius from floods while preserving capacity for other functions. A improves availability but doesn’t cap parallelism. B can change duration but not concurrency limits. D pre-warms capacity to reduce cold starts and can increase throughput, not restrict it. CEH-aligned hardening includes global/account concurrency limits, throttling at the edge (API Gateway, CDN, WAF), SQS buffering with redrive, and back-pressure-aware retries.

4. A red team wants persistence that is fileless (no new EXE on disk) and can be difficult to detect with simple file-system scanning. Which technique BEST fits that description on Windows?
A. Register a new Windows service that runs a signed-but-malicious executable.
B. Use a WMI permanent event subscription that executes a command line stored in the WMI repository.
C. Drop a DLL in C:WindowsSystem32 and rely on DLL search order hijacking.
D. Place a reverse shell binary in %APPDATA% and schedule it via Task Scheduler.
Correct Answer: B Explanation: Option B is correct because WMI permanent event subscriptions are fileless from the perspective of creating a new executable on disk: the trigger and command are stored in the WMI repository and the payload can be a PowerShell command or script executed in memory, making detection via file scanning ineffective; CEH highlights WMI subscriptions as a stealthy persistence method. Option A and D create on-disk artifacts (service executable, scheduled task referencing a binary) which are detectable by file-integrity and configuration audits. Option C adds a DLL on disk and relies on search order; it is persistent and stealthy to an extent but still creates a file that can be discovered via directory scans or code-integrity checks. Defenders should enumerate WMI (Get-WmiObject -Namespace rootsubscription -Class __EventFilter etc.), monitor for unusual consumer bindings, and implement WMI auditing.

5. A banking app uses TOTP-based MFA with a 30-second window but permits the same 6-digit code to be used multiple times within the window and across concurrent sessions. What risk is MOST directly introduced by this implementation?
A. Account lockout evasion due to rotating codes
B. Time skew denial-of-service if client and server drift
C. OTP brute force because the code space is small
D. MFA replay because the server does not enforce one-time use / nonce tracking for consumed codes
Correct Answer: D Explanation: Allowing reuse of the same TOTP within a validity window enables replay (D): an attacker who observes/intercepts a valid code (e.g., via shoulder surf, infostealer logs) can submit it again before expiry if the server doesn’t track “used” nonces. Lockout (A) is unrelated to one-time enforcement. Time skew (B) is usually mitigated by accepting ±1 window; it’s not the core risk here. Brute forcing (C) is limited by rate-limits and 10^6 code space; the immediate flaw is lack of per-code, per-user replay prevention. Fixes: single-use enforcement with server-side nonce/cache, short windows, step-up checks on anomalies, and adopting phishing-resistant factors (WebAuthn).

6. During a cloud penetration test, an ethical hacker discovers an externally reachable instance metadata service accessible via an SSRF vulnerability in a web application. Which immediate risk is the MOST critical to highlight to the client?
A. Denial-of-service against the instance via CPU credit exhaustion
B. Arbitrary file read on the underlying container filesystem
C. Privilege escalation to root on the host kernel via overlayfs
D. Credential theft enabling API calls in the victim’s account
Correct Answer: D Explanation: D is correct because SSRF access to an instance metadata endpoint can expose temporary credentials or tokens (e.g., IAM role credentials or service account tokens) that allow the attacker to call cloud APIs, pivot laterally, enumerate resources, and exfiltrate data; A is incorrect because CPU credit abuse is not the primary and immediate impact of metadata access; B is incorrect since SSRF to metadata is about HTTP requests to a link-local service, not arbitrary local file reads; C is incorrect because kernel-level privilege escalation is unrelated to metadata SSRF and would require a local exploit path, not a metadata token retrieval vector. CEH-relevant countermeasures include enforcing IMDS hardened modes (e.g., hop-by-hop tokens), metadata v2 protections, strict egress controls, WAF SSRF rules, and deny-by-default outbound policies.

7. A platform team wants an enforceable, cluster-wide baseline that prevents privileged pods, hostPath mounts, and root users by default, while allowing exceptions only via controlled policy. Which Kubernetes control is BEST suited to enforce this at admission time?
A. NetworkPolicy with default-deny ingress
B. Pod Security Admission (PSA) using the “restricted” level
C. RBAC Roles and RoleBindings for namespaces
D. DaemonSets that install host-based EDR agents
Correct Answer: B Explanation: Pod Security Admission (the built-in successor to PSP) can enforce the Pod Security Standards at admission—“restricted” denies privileged mode, hostPath, and other unsafe settings unless explicitly exempted; this is the correct preventive control for container hardening baselines. A is incorrect because NetworkPolicy governs L3/L4 traffic (ingress/egress), not pod privilege settings. C is incorrect since RBAC controls who can perform actions, not whether pod specs contain dangerous fields. D is incorrect because DaemonSets deploy agents, which can aid detection/response, but they do not enforce deployment-time policy. Many teams augment PSA with OPA Gatekeeper or Kyverno to express granular policies (e.g., deny runAsUser: 0, enforce readOnlyRootFilesystem, drop CAP_SYS_ADMIN).

8. You want to detect server-initiated outbound interactions (DNS/HTTP callbacks) that confirm out-of-band SQLi. Which integrated testing component best provides a controlled collaborator service to catch those callbacks during active testing?
A. sqlninja
B. Burp Intruder
C. Wireshark + tcpdump on the tester’s network
D. Burp Collaborator / Collaborator service
Correct Answer: D Explanation: Burp Collaborator (or equivalent collaborator/interact server) is a dedicated service designed to receive and display asynchronous DNS/HTTP callbacks initiated by the target server — precisely the mechanism used to validate OOB SQLi. sqlninja (A) targets MS SQL Server exploitation, particularly privilege escalation and OS pivoting, but it’s not a general collaborator capture service. Burp Intruder (B) automates payload delivery and fuzzing but does not provide an external callback listener. Wireshark/tcpdump (C) can capture on-network traffic but cannot reliably detect outbound DNS/HTTP requests originating from the target if they traverse networks outside the tester’s capture scope, and they lack the structured callback correlation features of a collaborator service. CEH best practice: use a collaborator/interact service to validate OOB techniques without producing ambiguous results.

9. During recon, you passively capture management frames: beacon, probe request/response, authentication, and association frames. You also note the network advertises “802.11w required.” Which statement best reflects the correct conceptual impact on common attack techniques?
A. PMF (802.11w) protects the 4-way handshake keys, making WPA2-PSK cracking infeasible
B. PMF (802.11w) encrypts beacon frames, preventing SSID enumeration via passive sniffing
C. PMF (802.11w) cryptographically protects certain management frames (e.g., deauth/disassoc), reducing classic deauthentication-based handshake captures and client kicks
D. PMF (802.11w) prevents all evil twin attacks by binding BSSID to the SSID cryptographically
Correct Answer: C Explanation: 802.11w (Protected Management Frames, PMF) adds integrity protection to certain management frames, notably deauthentication and disassociation, which mitigates spoofed deauth “kickoff” attacks that are traditionally used to force reauthentication for handshake capture; therefore C is correct. A is incorrect because PMF does not protect pairwise keys or change the feasibility of offline PSK cracking if a valid handshake is captured. B is incorrect because beacons remain in the clear (management frames are still discoverable), and SSID enumeration via passive sniffing is still possible. D is incorrect because PMF does not “bind” SSID and BSSID in a way that outright prevents evil twins; attackers can still stand up look-alike APs—client certificate validation and robust EAP configuration are the key defenses in Enterprise settings.

10. During a coordinated intrusion, attackers first executed credential theft from corporate IT, then used a VPN service account to access jump servers, and from there issued Modbus writes into the control network causing production shutdown. Which mitigation would BEST reduce the risk of this attack chain?
A. Implement network segmentation with strictly enforced jump hosts that perform application-layer protocol filtering, multi-factor authentication for jump server access, and just-in-time privileged access provisioning.
B. Allow all corporate users VPN access to the control network but audit logs weekly.
C. Use only IP-based ACLs on firewalls without multi-factor authentication to maximize availability.
D. Require users to use the same passwords across corporate and operational systems to simplify credential management.
Correct Answer: A Explanation: Defense-in-depth that includes strict segmentation, use of hardened jump hosts that enforce protocol filtering (disallow Modbus writes unless explicitly authorized), MFA for jump access, and just-in-time provisioning (reducing standing privileges) directly blocks lateral movement from IT to OT even if credentials are compromised. Option B (broad VPN access + weekly audits) is too permissive and slow to detect. Option C (IP-only ACLs without MFA) is weak—IP ACLs can be spoofed or misconfigured and do not prevent compromised credentials. Option D (password reuse) increases risk dramatically. Therefore A best mitigates the multi-stage attack described.

11. A target sits behind a CDN and an internal proxy. By crafting a request that includes both Transfer-Encoding: chunked and a conflicting Content-Length, the tester causes the front proxy and origin server to parse the request boundaries differently, letting a hidden request reach /admin uninspected. What attack is this?
A. Host header injection
B. HTTP response splitting
C. Directory traversal
D. HTTP request smuggling
Correct Answer: D Explanation: HTTP request smuggling abuses parsing discrepancies (e.g., CL.TE or TE.CL desynchronization) between intermediaries (CDN/WAF/proxy) and the origin to “smuggle” a request past security controls; tools like Burp Suite’s HTTP Request Smuggler or curl with raw payloads can demonstrate this. A is incorrect because host header injection poisons virtual-host routing or caches via a malicious Host/X-Forwarded-Host. B is incorrect since response splitting (CRLF injection) targets server-side header construction to create multiple responses or poison caches, not request boundary desync. C is incorrect as directory traversal manipulates path normalization (e.g., ../) to read files, unrelated to TE/CL parsing.

12. While assessing a mobile banking app that must maintain strong confidentiality on low-end Android handsets without AES-NI, you are asked to recommend a TLS record-protection algorithm that is resistant to timing attacks and performs well in software-only environments. Which choice is MOST appropriate?
A. AES-256-CBC with HMAC-SHA1
B. RSA-2048 for encrypting application data directly
C. ChaCha20-Poly1305 (AEAD)
D. 3DES-EDE-CBC with SHA-1
Correct Answer: C Explanation: ChaCha20-Poly1305 is an AEAD construction combining the ChaCha20 stream cipher with the Poly1305 authenticator; it is explicitly designed for high performance on devices without AES hardware acceleration and has constant-time implementations that reduce side-channel risk, making C correct. A is incorrect because CBC in TLS is legacy; it is vulnerable to issues like BEAST/Lucky13 and lacks built-in authentication (it relies on MAC-then-encrypt), making it more error-prone than AEAD. B is incorrect since RSA is an asymmetric algorithm used to encrypt small values (e.g., session keys) or for signatures; it is not used to encrypt bulk application data. D is incorrect because 3DES uses a 64-bit block size and is slow; it’s deprecated due to attacks like SWEET32 and should not be selected for modern TLS.

13. You resolve app.example.com and receive a CNAME chain: app.example.com → app.example.com.cdnprovider.net → edge-node-xyz.cdnprovider.net, with low TTLs and geo-varying A records. You must passively infer the likely origin hostname/network for scoping. What is the BEST next step?
A. Aggressively scan the edge IPs to fingerprint origins behind the CDN
B. Correlate historical passive DNS for example.com and CT entries for hostnames like origin.example.com or backend.example.com, then pivot on those to find non-CDN A/AAAA records
C. Request CDN provider support for origin disclosure using a spoofed customer ticket
D. Use HTTP header probing against app.example.com to elicit Via or X-Forwarded-For from the origin
Correct Answer: B Explanation: Passive pivots—historical passive DNS + CT—often reveal canonical origin hostnames (e.g., origin/ backend) that historically resolved directly to non-CDN addresses; those records, not the current edge, inform true asset scope without touching the target. A is active and noisy. C is social engineering and unethical. D involves direct probes to the target (active) and may be blocked by the CDN/WAF; it also isn’t guaranteed to surface origin details.

14. Your VPN uses IPsec with DH group 2 (1024-bit MODP) and static DH parameters shared across gateways. A security review warns of LOGJAM-style attacks and small-subgroup issues. Which change BEST mitigates these threats?
A. Keep MODP-1024 but rotate IKE pre-shared keys weekly
B. Switch to RSA key transport for IKE to avoid Diffie-Hellman entirely
C. Require (EC)DHE with strong, vetted groups (e.g., RFC-defined curves like secp256r1 or X25519) or at least DH groups ≥ MODP-2048 with unique, generator-verified parameters and reject weak groups in IKE policies
D. Disable PFS to reduce rekeying overhead
Correct Answer: C Explanation: LOGJAM and small-subgroup attacks target weak/old DH groups and shared/poor parameters. The fix is to use strong, vetted ephemeral groups—preferably ECDHE (e.g., X25519 or P-256)—or at minimum MODP-2048+ with high-quality parameters, and enforce policies rejecting weak groups; therefore C is correct. A (rotating PSKs) does not strengthen the DH math. B trades one design for another and may lose PFS if not combined with (EC)DHE. D (disabling PFS) worsens security posture and does not mitigate the cryptanalytic risk.

15. Under a passive-only constraint, you need to compile an initial list of corporate email addresses and hostnames by querying public search engines, PGP keyservers, and code repositories—then export results for de-duplication. Which tool is the MOST efficient starting point?
A. Nikto
B. theHarvester
C. ZAP (OWASP)
D. Netdiscover
Correct Answer: B Explanation: theHarvester aggregates emails, hostnames, and sometimes subdomains from public sources (search engines, PGP keyservers, GitHub, LinkedIn, etc.) and exports results, making it a top CEH choice for passive collection early in engagements. Nikto (A) is an active web server scanner (misconfig/vuln checks). ZAP (C) is an active web proxy/scanner for application testing, not OSINT harvesting. Netdiscover (D) is an ARP-based LAN host discovery tool—irrelevant for Internet-facing passive footprinting.

16. You are tasked with writing resilient YARA rules for a packed banking Trojan that decrypts in memory to a stable payload and mutex pattern. Which approach provides the BEST detection fidelity across variants?
A. Detonate/unpack the sample, extract stable post-unpack byte patterns (e.g., function prologues, protocol markers) and family-unique artifacts (mutex name/config keys), and build a condition requiring multiple of these indicators
B. Hash the entire on-disk file and alert on known SHA-256s observed in prior incidents
C. Match a single ASCII string in .rdata that appears in many current samples to avoid complexity
D. Key solely on compile timestamps and PE rich header values to identify the builder toolchain
Correct Answer: A Explanation: A is correct because crafting rules from stable post-unpack features plus family-unique artifacts (mutex/C2 config schema) yields robust, packer-agnostic detections; combine strings with byte patterns and sanity conditions (e.g., pe.is_32bit(), import presence after unpack) to reduce false positives. B (hashing) fails immediately on repacks/recompiles. C (single string) is fragile and easily stripped/obfuscated. D (timestamps/rich headers) are noisy, forgeable, and not family-unique enough. CEH emphasizes “generic detection” against polymorphic/packed families using dynamic-aided static indicators.

17. A microservice API uses OAuth 2.0 access tokens with scopes. Using a token bearing only scope="read:profile", you can still call DELETE /api/users/{id} successfully. Token validation verifies signature, iss, aud, and expiration but does not check scope. What is the MOST precise description of the flaw?
A. redirect_uri is not strictly allowlisted, enabling token leakage
B. Failure to enforce authorization based on OAuth scopes/claims (least-privilege not checked at the resource server)
C. Missing PKCE on the client, allowing code interception
D. IDOR, because the user ID is in the path
Correct Answer: B Explanation: The resource server must map protected operations to required scopes/claims and deny calls when the presented token lacks them; accepting a read-only token for a destructive DELETE is an authorization enforcement failure (B). redirect_uri (A) and PKCE (C) relate to the authorization flow (authentication/authorization code security), not resource authorization decisions. IDOR (D) is about object ownership; even with the correct user ID, the operation must be scoped to allowed privileges. Fix by implementing precise scope checks (e.g., delete:user) and/or ABAC policies at the PEP, testing with negative cases, and avoiding “permit by default” logic.

18. You plan a decoy-assisted SYN scan from the Internet against an IPS-protected range. Which statement BEST reflects how decoys work and a key operational risk?
A. Decoys ensure only decoy IPs appear in logs; your true source is never visible if you include at least five decoys.
B. Decoys route replies back through the decoy IPs which your scanner collects via raw sockets.
C. Decoys send unauthenticated HTTP requests via proxies; SYN scans cannot use decoys.
D. Decoys inject additional spoofed sources; the target often still receives and may log your real source, and misusing arbitrary third-party IPs can amount to scan proxying/DoS against those parties.
Correct Answer: D Explanation: Nmap’s -D adds spoofed sources to obscure attribution, but the target still typically receives your real packets and may correlate them (e.g., timing, TTLs, partial TCP characteristics). CEHv13 warns that decoys don’t guarantee anonymity and can create collateral noise/abuse toward unwitting decoy hosts, raising ethical and legal concerns. Option A overpromises. Option B misunderstands routing—replies go to the IP they’re addressed to, not back to you through the decoys. Option C is wrong—SYN scans support decoys; proxies are unrelated to decoy mechanics.

19. A company using BitLocker enables “BitLocker To Go” for removable drives. Which feature does this provide?
A. Encrypts removable media with AES and allows access on other systems with a password or smart card
B. Provides secure boot by verifying the integrity of removable devices
C. Automatically mounts encrypted removable drives on any Windows system without user interaction
D. Encrypts removable media using RSA with TPM integration
Correct Answer: A Explanation: BitLocker To Go encrypts removable media (USB, external drives) using AES, requiring a password or smart card for access across systems, making A correct. B refers to Secure Boot, not BitLocker. C is wrong because access requires credentials; auto-mount would undermine security. D is incorrect—BitLocker uses symmetric AES, not RSA, for encryption.

20. A client mandates that any device management traffic must ensure confidentiality and integrity with mutual identity verification. Which SNMP configuration BEST satisfies this requirement while remaining standards-compliant and widely supported?
A. SNMPv2c with per-subnet ACLs on UDP/161 and randomized community strings
B. SNMPv3 with noAuthNoPriv and strict VACM views for read-only access
C. SNMPv2c with “private” as RW and “public” as RO, restricted to the NMS IPs
D. SNMPv3 with authPriv (e.g., SHA-256 for auth, AES-128/256 for privacy) and USM users bound to strict VACM views
Correct Answer: D Explanation: Only SNMPv3 with authPriv provides both authentication (data origin + integrity) and privacy (encryption) with per-user credentials under the User-based Security Model (USM), and combining this with VACM views enforces least-privilege OID access (D). Option A still transmits communities in cleartext and offers no cryptographic integrity; ACLs reduce exposure but do not secure the content. Option B (noAuthNoPriv) lacks both confidentiality and integrity, providing only minimal message timeliness checks. Option C leaves RW/RO communities exposed in plaintext and is a known anti-pattern; limiting source IPs is not a substitute for cryptographic protection.

21. During analysis of a login workflow in Burp Suite, you notice the application issues a session cookie (JSESSIONID) to unauthenticated users on the login page and does not change the cookie value after a successful login. What threat is MOST accurately indicated by this behavior?
A. Session fixation due to lack of post-authentication session ID regeneration
B. Credential stuffing is possible because the cookie value is predictable
C. CSRF is possible because the cookie lacks the SameSite attribute
D. Replay attacks are inevitable because TLS is not in use
Correct Answer: A Explanation: Failing to rotate the session identifier after privilege elevation is classic session fixation (A), where an attacker can pre-establish or set a victim’s session and ride it through authentication; the fix is to regenerate the session ID at login and invalidate the prior session. Predictability (B) is a different problem (weak entropy) and is not evidenced by the observation that the value simply persists. SameSite (C) impacts CSRF risk but is not the core issue here; CSRF can still be mitigated with tokens/origin checks even without SameSite. Replay (D) is not supported by the evidence and modern apps should be on TLS; replay typically involves capturing and reusing tokens within validity windows, not merely seeing a static cookie across auth.

22. You are tasked with mapping an organization’s externally routable netblocks and the originating Autonomous System (AS) numbers using only open-source methods. Which action provides the MOST accurate starting point with minimal intrusion?
A. Launch an Internet-wide SYN scan on common ports to discover live IP ranges and infer ownership from banners
B. Query RDAP/WHOIS records for the legal entity’s registered allocations to list netblocks and origin ASNs
C. Perform SNMP walks of perimeter routers to enumerate interfaces and BGP peers
D. Simulate a BGP route injection from a lab to observe accepted prefixes for the target AS
Correct Answer: B Explanation: RDAP/WHOIS provides authoritative ownership data, including netblocks, Org IDs, and often origin ASN details, making it the correct, low-touch first step in footprinting (MITRE T1596.003 – WHOIS). Option A is noisy, ethically questionable at the footprinting phase, and inefficient compared with registry data. Option C requires credentials and access to the target’s routers—unrealistic and out of scope. Option D would be unethical and illegal; lab-based route manipulation toward production is never appropriate for reconnaissance.

23. Your SOC designs a new SIEM correlation that alerts when a user authenticates into the VPN from Lagos and, within 15 minutes, successfully authenticates into O365 from Tokyo. What control function best characterizes this use case?
A. Preventive
B. Corrective
C. Deterrent
D. Detective
Correct Answer: D Explanation: Detective controls identify undesirable events after or as they occur. A SIEM correlation for impossible travel is quintessentially detective—its purpose is to alert for investigation and response (e.g., incident triage, MFA reset), not to block. A (preventive) would include MFA, conditional access, geofencing, device posture checks that stop the login. B (corrective) restores normal operations after an incident (e.g., account reset, system rebuild). C (deterrent) aims to discourage violations (e.g., banners, visible cameras) rather than identify them in telemetry. In CEH, clearly distinguishing preventive/detective/corrective/deterrent/compensating is foundational to control design.

24. You need to assess how well a domain resists spoofing by enforcing alignment between visible headers and authenticated identities. Which DNS control MOST directly supports this objective?
A. DMARC TXT record at _dmarc.example.com with an enforcing policy (e.g., p=quarantine/reject)
B. SPF TXT record at example.com with include statements only
C. DKIM public key TXT record at selector._domainkey.example.com without a policy
D. MX records pointing to the organization’s inbound provider
Correct Answer: A Explanation: DMARC enforces identifier alignment between the domain in the From: header and authenticated domains from SPF and/or DKIM, allowing policy-based actions (quarantine/reject) and reporting (rua/ruf). This is the control that directly mitigates spoofing of visible sender domains. B) SPF authenticates the envelope MAIL FROM (return-path) and/or HELO but alone does not enforce alignment with the human-visible From:. C) DKIM provides message integrity/authentication for a signing domain but, absent DMARC, does not mandate alignment with the From: domain. D) MX records indicate where mail is received; they neither authenticate senders nor enforce header alignment.

25. A tester runs nmap -p 80,443 --script http-vuln* and follows with nikto and gobuster to identify vulnerable scripts, misconfigurations, and hidden directories. In the CEH web server attack methodology, what stage does this sequence represent?
A. Clean-up and log removal
B. Post-exploitation lateral movement
C. Vulnerability scanning and content discovery
D. Social engineering pretexting
Correct Answer: C Explanation: Vulnerability scanning and content discovery best describes this activity: nmap with HTTP vulnerability scripts, nikto for server misconfigurations and known vulnerabilities, and gobuster or dirsearch for forced browsing are standard tools used in this stage to enumerate potential attack vectors (scripts, backup files, admin panels). Option A is incorrect because cleanup/log removal occurs after exploitation to hide traces. Option B is incorrect as lateral movement follows initial compromise and involves pivoting to internal hosts. Option D is unrelated — social engineering targets humans rather than performing automated vulnerability scanning.

26. A refinery wants to prevent unauthorized Modbus/TCP writes from corporate IT into Level 1/2 PLCs while preserving legitimate supervisory reads. Which single architectural control most effectively reduces this risk with minimal operational impact?
A. Move SCADA and historians to the enterprise LAN (Level 4) and NAT PLCs behind the core firewall
B. Deploy an Industrial DMZ (Level 3.5) with an ICS-aware firewall/proxy that enforces default-deny rules, write-function allowlisting, and read-only brokering to PLCs
C. Enable VLANs across the plant floor so Modbus uses a different broadcast domain than IT devices
D. Tunnel all OT traffic inside IPsec from IT to OT to ensure confidentiality over the wire
Correct Answer: B Explanation: An Industrial DMZ following Purdue and IEC 62443 guidance with protocol-aware deep packet inspection (DPI) can broker supervisory reads while denying or strictly allowlisting Modbus write function codes, providing granular control without touching PLC firmware; this is the most impactful and least disruptive countermeasure. A expands exposure by collapsing segmentation. C (VLANs) is helpful but insufficient because L3 routing still permits unauthorized writes without DPI and policy. D (IPsec) encrypts traffic but preserves insecure application semantics; it can protect malicious writes rather than prevent them.

27. When generating a Certificate Signing Request (CSR) for a public website, which field is CRITICAL for modern browsers to accept the certificate as valid?
A. The Common Name (CN) field in the Subject must exactly match the FQDN
B. The Organizational Unit (OU) must be included in the Subject
C. The Subject Key Identifier must be present and unique

28. During QA, a critical finding is disputed by the system owner; credentialed checks show the patched version is present and a targeted manual test fails to reproduce the issue. How should this outcome be reflected in the final report?
A. Delete the finding entirely to avoid confusion in the metrics.
B. Keep it as “Critical” but add a note that remediation is not required.
C. Downgrade to “Informational” and remove all references to the original scanner plugin.
D. Mark the finding as “False Positive—Closed,” include the verification steps (tool/plugin IDs, versions, timestamps, command excerpts), and update metrics to exclude it from open-risk counts.
