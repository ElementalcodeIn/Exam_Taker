1. Which Windows mechanism allows an attacker to store data in a file system location that is not shown by ordinary directory listings (e.g., dir or Explorer), and is commonly abused to hide small files or payloads without creating visible files?
A. NTFS Alternate Data Streams (ADS)
B. FAT32 hidden attribute bit
C. BitLocker encrypted container
D. NTFS compression via Compact attribute
Correct Answer: A Explanation: Option A is correct because NTFS Alternate Data Streams (ADS) provide additional named streams attached to a file (or directory) that are not visible in normal directory listings and are not separate filesystem entries; attackers can hide small payloads, configuration data, or shellcode in ADS and the data will often be invisible to casual inspection. CEH covers ADS as a stealthy storage technique and defenders search for streams (forensic tools and PowerShell modules can enumerate them). Option B is incorrect because FAT32’s “hidden” attribute is a visible filesystem metadata flag that Explorer and dir will respect (hidden files can be revealed by changing view settings), whereas ADS are not separate directory entries. Option C (BitLocker) is encryption-at-rest for volumes; it protects confidentiality but is not a hiding mechanism for covert storage within an existing file system namespace. Option D (NTFS compression) simply compresses the primary data stream to save space; it does not create a hidden secondary stream and is not intended or typically used to conceal separate payloads. Defensive controls include scanning for ADS, enabling file-integrity monitoring, and restricting write access to high-risk locations.

2. A camera vendor’s OTA process was abused to push altered firmware to a historian-adjacent appliance. What countermeasure most robustly protects the firmware supply chain end-to-end?
A. Signed firmware with an immutable root-of-trust (secure boot) verified by the bootloader before install, using offline-protected signing keys, version rollback protection, and staged/canary rollout controls
B. Hosting updates on HTTPS with a valid public CA certificate
C. Packing binaries with UPX to deter reverse engineering
D. Hashing the file on the update server and publishing the hash on the vendor blog
Correct Answer: A Explanation: Only a device-enforced chain of trust (secure boot + signature verification using keys outside the update server’s control), plus rollback protection and staged deployment, resists server compromise and MITM; it ensures only vendor-authorized images are accepted. B (HTTPS) secures transport but not the image if the server is compromised. C (obfuscation) is not a security boundary. D (published hashes) can be spoofed alongside a compromised server and is not verified by the device, so it lacks enforceability.

3. Which sequence most accurately represents a standard, defensible SQL injection testing methodology from reconnaissance through reporting?
A. Exploit -> Escalate -> Discover -> Report -> Clean up
B. Discover injection points -> Fingerprint DBMS -> Validate via controlled probes -> Safely extract data (if authorized) -> Document evidence and remediation -> Clean up/restore
C. Run a full automated scan -> Exploit every positive finding -> Erase all logs to hide activity -> Report findings without reproduction steps
D. Random fuzzing of all inputs -> Immediate UNION extraction -> Publish findings on public channels to pressure the client
Correct Answer: B Explanation: Option B describes the correct, defensible workflow: first discover injection points, then fingerprint the DBMS, validate using controlled, non-destructive probes, extract data only if in scope and authorized (with caution), thoroughly document evidence and remediation steps, and clean up or restore any changed state. This flow aligns with CEH best practices and professional engagement rules. Option A is unordered and irresponsible (exploitation before discovery is illogical). Option C is unethical and dangerous (erasing logs and indiscriminately exploiting). Option D is chaotic, unprofessional, and could lead to legal/contractual violations; responsible methodology avoids random destructive actions and public disclosure.

4. A financial services company wants to prevent malware from exploiting unpatched browsers and plug-ins. Which defense is MOST aligned with CEH malware countermeasures?
A. Implementing application whitelisting and auto-patching software updates
B. Disabling TLS 1.2 to force clients to use TLS 1.3 only
C. Creating a DNS blacklist of all non–.com domains
D. Instructing employees to avoid browsing social media websites
Correct Answer: A Explanation: A is correct because malware often exploits outdated software; auto-patching reduces exploitable vulnerabilities, and application whitelisting ensures only trusted binaries run. B (TLS 1.2 disabling) doesn’t address malware exploits. C (non-.com blocklists) is arbitrary and easily bypassed. D (user instruction alone) is insufficient; attackers exploit trusted sites and drive-by downloads. CEH stresses layered defense: patching, whitelisting, sandboxing, and hardening browsers.

5. You have brief, legitimate physical access to an unlocked Android device where Developer Options are enabled. The target app’s manifest shows android:allowBackup="true" and no custom backup rules. Which technique most directly enables extraction of the app’s data for analysis?
A. Trigger BLE pairing with the app’s wearable companion and pull data from GATT characteristics
B. Use logical backup mechanisms (e.g., ADB/Auto Backup) to obtain the app’s private files and databases
C. Attempt kernel privilege escalation to dump /data using an n-day exploit
D. Perform Wi-Fi deauthentication to capture WPA2 handshakes for later decryption of app traffic
Correct Answer: B Explanation: With allowBackup=true, Android’s backup transports (including ADB in appropriate contexts or Auto Backup to eligible storage) can include app-private data unless excluded/encrypted by policy—so B is correct. BLE pairing (A) concerns radio peripherals and won’t access private app storage. Kernel exploitation (C) is unnecessary, high risk, and out of scope when backup is allowed. 6. A privileged dashboard is fronted by a CDN. Responses include Cache-Control: public, max-age=900 with no Vary on Cookie or Authorization. After an admin views the page, some unauthenticated users intermittently receive the admin-rendered dashboard from the CDN. What vulnerability BEST fits this behavior?
A. CSRF due to sensitive actions accessible via GET
B. Insecure CORS allowing credentialed cross-origin reads
C. Missing HSTS permitting downgrade attacks
D. Authorization-unaware caching (cache key lacks user/auth context), leading to cache poisoning/leakage
Correct Answer: D Explanation: Marking authenticated, user-specific content as public and omitting Vary on identity signals lets a shared cache serve privileged content to other users—an authorization failure at the caching layer (D). CSRF (A) is about forging requests, not serving someone else’s cached response. CORS (B) is unrelated: the CDN leaks to any requester regardless of origin. HSTS (C) ensures HTTPS but does not prevent serving cached admin content to others. Fix by using Cache-Control: private, no-store for personalized pages or segmenting cache keys by Authorization/Cookie/surrogate key and validating headers at the edge.

7. During mutual TLS testing, the client’s certificate is accepted by the server’s CA chain, but authentication consistently fails. On inspection, the certificate lacks the Client Authentication OID in the Extended Key Usage field. What is the MOST likely cause?
A. The certificate was signed with RSA instead of ECC
B. The certificate does not include a Subject Key Identifier
C. The certificate is missing the correct Extended Key Usage for client authentication
D. The certificate chain uses SHA-1 instead of SHA-256
Correct Answer: C Explanation: In mTLS, the client’s certificate must include Extended Key Usage (EKU) with Client Authentication OID (1.3.6.1.5.5.7.3.2). Without this, the server rejects it even if it is signed by a trusted CA, making C correct. A is wrong because RSA vs ECC does not affect authentication validity if supported. B is incorrect—Subject Key Identifier helps with path building but isn’t mandatory for client auth. D is wrong because SHA-1 affects trustworthiness but does not directly block EKU-based client auth. CEHv13 stresses knowledge of EKU fields for proper certificate functionality.

8. An attacker is push-bombing engineers with dozens of MFA approvals at 02:00, eventually coercing a tired user to tap “Approve.” Which control is the MOST effective technical countermeasure against this class of social engineering?

B. Increase security-awareness frequency from annual to quarterly
C. Lock accounts for 60 minutes after five denied push prompts
D. Replace push approvals with phishing-resistant FIDO2/WebAuthn authenticators and enable number-matching / rate-limiting for any residual push flows
Correct Answer: D Explanation: D directly neutralizes consent-coercion by eliminating phishable/push-based approvals in favor of origin-bound FIDO2/WebAuthn, while adding number-matching and rate limits where push persists; this addresses both the human and protocol vectors and is current best practice. 9. While testing a single-page application (SPA), you find that sensitive data such as API keys and user tokens are stored in localStorage. Why is this a client-side security concern?
A. localStorage is encrypted by the browser and safe from all attackers
B. Any script running in the browser context, including injected malicious JavaScript from an XSS attack, can access localStorage values
C. localStorage enforces SameSite rules, making CSRF impossible
D. Values in localStorage are automatically protected by TLS
Correct Answer: B Explanation: Storing sensitive values in localStorage is dangerous because they are accessible to any JavaScript executing in the page context, including malicious scripts injected via XSS (B). Option A is false: there is no encryption at rest in the browser. Option C is misleading: SameSite affects cookies, not localStorage. Option D is irrelevant because TLS protects in transit but not storage within the client. Best practice is to store session tokens in Secure; HttpOnly; SameSite cookies.

12. You are testing an enterprise NFS deployment. rpcbind (TCP/111) responds and UDP/TCP 2049 are reachable. You need to enumerate export paths and client restrictions before attempting any mounts. Which single action MOST directly achieves this?
A. Run nmap --script nfs-ls -p 2049 <target> to list files in exported directories
B. Query rpcbind with rpcinfo -p <target> and assume any nfs/mountd program numbers equal mountable exports
C. Perform a SYN scan on all high ports to find mountd and infer exports from open ports
D. Use showmount -e <target> to request the export list (paths and access controls) from mountd
Correct Answer: D Explanation: showmount -e queries the mountd service to return the export list (paths and client/netgroup restrictions) and is the canonical first step for NFS enumeration (D). nfs-ls (A) attempts directory listing of already mounted exports and presumes you can mount or that NFSv4 is configured to expose a pseudo-root; it’s not the discovery step. rpcinfo -p (B) only shows registered RPC programs and versions, not the export table. A high-port SYN scan (C) may locate mountd’s dynamic port, but it won’t disclose which directories are exported or their access controls.

13. A program manager asks for a quarterly cycle that begins with discovery scans, proceeds to validated credentialed scans, and ends with selected manual verification of critical web findings before reporting. Which classification BEST describes this end-to-end methodology?
A. External black-box penetration test with exploit development focus
B. Continuous monitoring only, using passive sensors and threat intel feeds
C. Layered vulnerability assessment program combining unauthenticated discovery, authenticated host assessment, and targeted manual application validation (DAST)
D. Single-phase compliance audit aligned solely to CIS benchmarks
Correct Answer: C Explanation: D is incorrect because an exploit-centric pen test is goal-oriented and not the described cyclical assessment flow. B is incorrect because the workflow includes active scanning and manual validation, not passive-only monitoring. D is incorrect again because a single-phase benchmark audit omits discovery scans and manual application validation. C is correct as it accurately reflects a layered vulnerability assessment program typical in CEHv13 practice: initial unauthenticated discovery (e.g., Nmap/host discovery), followed by authenticated host scanning (e.g., Nessus/Qualys/OpenVAS with credentials) for accurate patch/config state, and selective manual DAST validation of web findings (e.g., Burp/ZAP) to reduce false positives before formal reporting.

14. Your organization wants to degrade the fidelity of large-scale UDP service discovery on Internet-facing ranges without breaking production apps. Which network control MOST directly reduces the effectiveness of mass UDP scans?
A. Enable PMTU black-hole detection on routers.
B. Configure hosts and firewalls to silently drop (or heavily rate-limit) ICMP Destination Unreachable—Port Unreachable (Type 3, Code 3) for closed UDP ports.
C. Block ICMP Echo Requests globally.
D. Disable TCP window scaling on edge servers.
Correct Answer: B Explanation: UDP scanning typically classifies a port as “closed” only upon receiving ICMP Type 3 Code 3. By dropping or throttling these messages, defenders force scanners to see silence, yielding “open|filtered” and greatly reducing the attacker’s ability to map UDP exposure; this must be balanced against troubleshooting needs since suppressing ICMP can hinder diagnostics. PMTU features (A) don’t affect UDP port state classification. ICMP Echo filtering (C) pertains to ping sweeps, not UDP port discovery. TCP window scaling (D) has no bearing on UDP.

15. The client wants an external test that realistically simulates an internet-based adversary with no internal knowledge or credentials. Which testing approach best fits this requirement?
A. White-box testing
B. Crystal-box testing with developer interviews

Correct Answer: D Explanation: Black-box testing simulates an attacker with no prior internal knowledge (no creds, code, or architecture docs); therefore D is correct. C (gray-box) grants partial knowledge (e.g., limited creds, network maps) and does not fully model an uninformed external adversary. 16. You discover TCP/445 open on a Windows server while TCP/139 and UDP/137/138 are closed (NetBIOS over TCP/IP disabled). You need domain and share reconnaissance with minimal privileges. Which approach is MOST effective?
A. nbtstat -A <IP> to retrieve the NetBIOS name table for users and shares
B. net view <IP> /all using the current workstation context to list everything
C. enum4linux -a <IP> to drive SMB/RPC (e.g., SAMR/LSARPC/SRVSVC) enumeration over 445 with null/guest where possible
D. Launch LLMNR spoofing (Responder) to coerce credentials and infer shares from captured hashes
Correct Answer: C Explanation: With NetBIOS disabled, NBNS/NBTSTAT (A) won’t work; SMB still runs natively over 445, and enum4linux aggregates numerous RPC calls (SRVSVC for shares, SAMR for users/groups, LSARPC for policies) to enumerate rich data even with null/guest access (C). net view (B) may require valid credentials and often returns limited data. LLMNR spoofing (D) is an active credential-coercion attack, not direct enumeration of the target’s shares or domain info; it also risks detection and is outside “enumeration via service” scope.

17. A web application is protected by a simple WAF that blocks common SQL metacharacters and known attack signatures. During testing you find that sending UN/**/ION/**/SELEC/**/T allows a UNION payload to succeed while UNION SELECT is blocked. Which evasion technique does this demonstrate?
A. Inline comment obfuscation (inserting comments inside keywords)
B. Base64-encoding the entire payload and relying on the server to decode it
C. Using stacked queries to append another statement after the original
D. Forcing the DBMS to use OOB DNS callbacks for exfiltration
Correct Answer: A Explanation: Correct — Option A (inline comment obfuscation) inserts SQL comments (e.g., /**/) or other benign tokens inside SQL keywords to break simple signature-based WAF pattern matching while leaving the DBMS parser able to reassemble the keyword (UN/**/ION -> UNION). This is a classic evasion technique often used alongside other obfuscations (case-mixing, whitespace substitution). Option B (base64-encoding) would only work if the application decodes input server-side before SQL execution; this is uncommon for typical form parameters and is not what the example shows. Option C (stacked queries) is a different technique that executes multiple statements via statement delimiters (e.g., ;) and does not explain why inserting inline comments inside keywords would succeed. Option D (OOB DNS callbacks) is an exfiltration channel, not an evasion of keyword-based WAF signatures. In CEHv13 practice, inline-comment obfuscation is an explicit evasion taught for bypassing naïve pattern-based defenses.

18. During passive profiling, you collect robots.txt and sitemap.xml from the primary domain. What is the MOST accurate way these artifacts should influence your web infrastructure footprinting?
A. Use them to derive candidate paths and endpoints (including disallowed admin/debug routes), then corroborate with archival sources (Wayback Machine, URL indexes) and cautiously probe with HEAD/GET; they are reconnaissance inputs, not vulnerabilities by themselves
B. Treat any Disallow entry as proof of a critical access control flaw and report immediately
C. Ignore robots.txt because compliant crawlers never index sensitive paths and attackers can’t access them
D. Use sitemap URLs only for SEO context; they have no value in security testing
Correct Answer: A Explanation: robots.txt and sitemap.xml often expose otherwise unlinked endpoints and historical routes; in footprinting, you mine these files to seed endpoint lists and then validate safely (e.g., HEAD, low-rate GET), potentially discovering admin panels, feature flags, or legacy APIs. They are not vulnerabilities on their own—access controls must still be tested. Declaring every Disallow a flaw (B) is incorrect. Ignoring robots (C) misunderstands that attackers do not honor crawler conventions. Dismissing sitemaps (D) wastes a rich source of structured URLs that often include versioned or language-specific paths useful for breadth coverage.

19. You capture the following NBSTAT snippet for a domain member: “ACME GROUP” “ACME GROUP” “ACME UNIQUE” “WS-ENG-12 UNIQUE” Which entry BEST indicates the list of all domain controllers registered for the domain?
A. ACME <1B> UNIQUE
B. ACME <1D> UNIQUE
C. ACME <1C> GROUP
D. ACME <00> GROUP
Correct Answer: C Explanation: The GROUP name is registered by all domain controllers in the domain and is used to locate DCs for services like logon and LDAP/Kerberos referral (C); this is the most reliable NBSTAT indicator of DC presence as a set. UNIQUE (A) is the Domain Master Browser, typically the PDC Emulator—one system, not all DCs. UNIQUE (B) would represent a local Master Browser on a subnet (not shown here and unrelated to DCs). GROUP (D) is the workgroup/domain name for browser service purposes, not specific to DCs and generally registered by many systems, making it a poor DC enumerator.

20. A security team is standardizing their IPsec ESP configurations and wants a single cipher suite that provides confidentiality and integrity in one primitive and is widely supported by modern stacks. Which option is the BEST choice?
A. AES-256-CBC for encryption and HMAC-MD5 for integrity
B. 3DES-EDE-CBC with HMAC-SHA1 for backward compatibility
C. AES-128-GCM (AEAD) for ESP
D. RC4-HMAC for ESP to reduce CPU cost
Correct Answer: C Explanation: AES-GCM is an AEAD mode standardized for IPsec ESP that provides authenticated encryption in one construction, reduces complexity (no separate MAC to configure), and is widely supported in modern VPN implementations, making C correct. A combines CBC (which lacks built-in integrity) with a weak HMAC choice (MD5) and is not recommended. B relies on 3DES and SHA-1—both legacy and discouraged due to performance and security concerns (e.g., SWEET32 and SHA-1 deprecation). D is incorrect because RC4 is not appropriate for IPsec ESP and is widely deprecated due to significant cryptographic weaknesses.

21. An engineering team built an internal service using AES-GCM but implemented a device-scoped 96-bit nonce that is randomly generated once and then reused for every message from that device. What countermeasure MOST directly prevents catastrophic GCM nonce-reuse failures?
A. Keep the single random nonce but upgrade the key to AES-256-GCM
B. Generate a unique per-message 96-bit nonce (e.g., an atomic counter combined with a device-unique prefix), enforce rekeying before counter wraparound, and use a vetted library that guarantees nonce uniqueness
C. Switch to AES-CBC with a zero IV to eliminate nonce requirements
D. Append a SHA-256 checksum to the ciphertext to detect reuse
Correct Answer: B Explanation: AES-GCM requires a unique nonce per key; reuse breaks both confidentiality and integrity. The fix is to guarantee per-message nonce uniqueness (counter-based or secure RNG), rekey before wrap, and rely on vetted libraries that enforce this invariant; thus B is correct. A (AES-256) does not mitigate nonce reuse. C replaces one serious flaw with another (CBC with static IV is insecure and still needs authentication). D adds a non-keyed checksum that does not prevent or detect GCM-forgery conditions.

24. A 700-Gbps CLDAP/DNS reflection saturates the link to your data center. Servers and WAFs are healthy but unreachable due to bandwidth exhaustion. What is the MOST effective immediate action to restore availability to critical services?
A. Scale out the web tier and increase auto-scaling thresholds
B. Add stricter WAF rules and CAPTCHAs on login endpoints
C. Tune Linux network stacks (e.g., net.core.somaxconn) to increase queue depths

25. For application-level interception, modifying HTTP requests/responses, and session token manipulation while testing web apps (including automated replay and scripting), which tool is the industry standard proxy?
A. ZAP (OWASP Zed Attack Proxy)
B. mitmproxy
C. Burp Suite
D. Nikto
Correct Answer: C Explanation: Burp Suite is the industry standard interception proxy used by web application testers to intercept, inspect, modify, and replay HTTP/HTTPS requests and responses, tamper with cookies/session tokens, run automated scanners, and chain modules (Intruder, Repeater, Sequencer) for session-related analysis — it’s the canonical application-level tool in CEH/OWASP testing. ZAP (A) is a capable open-source proxy with many of the same features and is widely used (especially for automation), but Burp is often regarded as the more feature-rich, commercial standard in professional web app testing. mitmproxy (B) is a scriptable, lightweight interception proxy that is excellent for automated and programmable MITM tasks (and may be preferred for scripting), but Burp provides a more complete suite of web security testing modules and a GUI geared to manual app-level session analysis. Nikto (D) is a web server scanner that finds misconfigurations and known issues — it does not provide interactive request/response interception or token manipulation.

28. A security team detects widespread ARP spoofing alerts affecting multiple VLANs. As a defender, which switch-side control most directly mitigates this sniffing vector by validating ARP packets against trusted bindings at Layer 2?
A. MACSec (802.1AE) with AES-GCM on trunk links
B. 802.1X EAP-TLS with per-port authentication
C. Dynamic ARP Inspection (DAI) with DHCP snooping-built bindings
D. IP Source Guard with source IP/MAC filtering on routed interfaces
Correct Answer: C Explanation: Dynamic ARP Inspection (DAI) (C) inspects ARP packets on untrusted ports and validates sender IP/MAC pairs against the DHCP snooping binding table (or static entries), actively blocking ARP spoofing used for sniffing/MITM. MACSec (A) encrypts link-layer traffic between nodes (e.g., on trunks) but does not inspect or block forged ARP on access ports. 802.1X (B) authenticates endpoints but does not validate ARP content once a device is on the network. IP Source Guard (D) enforces source integrity for IPv4/IPv6 but focuses on IP address spoofing at Layer 3 and does not specifically validate ARP opcodes/contents like DAI does.

29. You need to dynamically analyze a suspicious PE that appears to require outbound HTTP(S) before it will unpack and beacon. Your goal is to observe C2 behavior and extract IOCs without risking egress to the Internet. Which lab setup is MOST appropriate?

Correct Answer: B Explanation: B is correct because host-only isolation plus protocol emulation (FakeNet-NG/INetSim) lets you coerce the sample to reveal DNS/HTTP(S)/SMTP behaviors and endpoints while preventing true egress, yielding safe network and process telemetry for IOC extraction (PCAP, logs). Correct Answer: B Explanation: Option B is correct because DLL search-order hijacking/side-loading leverages the loader’s search for missing DLLs; with SafeDllSearchMode, the application directory remains a high-priority search location. Option A is incorrect because with SafeDllSearchMode enabled the application directory is searched before System32 for DLLs explicitly loaded without full paths; also writing to System32 typically requires admin rights. Option C conflates Winlogon credential providers (legacy GINA) with DLL injection and is unrelated to this service’s load behavior. Option D is invasive, risks corruption, and requires privileges; exploitation here is achieved passively via the search order. Mitigations include using full DLL paths, code signing validation, and application whitelisting.

116. An ISP collaborates with a CERT to disrupt an active IoT DDoS botnet. They redirect the botnet’s C2 domains to controlled servers that accept connections and issue no harmful commands, while gathering victim IPs for remediation. What is this defensive action called?
A. RTBH blackholing
B. BGP Flowspec mitigation
C. Sinkholing
D. Greylisting
Correct Answer: C Explanation: Sinkholing re-points malicious domains/IPs to infrastructure controlled by defenders, capturing callbacks safely and enabling telemetry and cleanup without executing attacker commands. Option A (Remote Triggered Black Hole) discards traffic by routing to null; it gathers no intelligence. Option B (BGP Flowspec) distributes filtering/rate limits for specific traffic patterns but does not re-home C2. Option D (greylisting) is an email anti-spam tactic involving temporary rejections, not applicable to botnet C2 disruption.

117. An organization suffers frequent deauthentication-based handshake captures and client disconnects during assessments. Which countermeasure most directly mitigates these spoofed deauth/disassociation attacks on modern Wi-Fi networks?
A. Reduce AP transmit power to limit an attacker’s reception range
B. Disable SSID broadcasting so clients won’t see the network in scans
C. Enforce Protected Management Frames (PMF / 802.11w) and require PMF-capable clients
D. Enable MAC address filtering on the AP to reject unknown clients
Correct Answer: C Explanation: Correct Answer: C — Enforcing Protected Management Frames (PMF, IEEE 802.11w) cryptographically protects specific management frames (notably deauthentication and disassociation), preventing unauthenticated spoofed deauths from being accepted by compliant clients; this directly mitigates the classic deauth-for-handshake-capture and DoS technique. A is incorrect because lowering transmit power reduces range but does not stop an attacker who is physically close or using a high-gain antenna — it’s a poor substitute for PMF. B is incorrect since hiding the SSID (disabling SSID broadcast) is security through obscurity: it does not prevent spoofed deauth frames and often breaks legitimate roaming/scanning behavior. D is incorrect because MAC filtering is trivial to bypass (MAC spoofing) and does not protect against management-frame spoofing; furthermore, it increases administrative overhead and can block legitimate devices.

118. You need to prioritize web hosts discovered during footprinting for follow-up security testing. Which triage metric combination MOST aligns with CEH methodology to produce a risk-based ordering?
A. Public exposure score (internet routable + open services), business criticality (customer-facing/payment/exec), and evidence of known-vulnerable software (observed banners, public CVEs) combined into a weighted risk score
B. Alphabetical hostname ordering to ensure systematic scanning coverage
C. Size of the homepage in bytes only, because larger pages mean more complexity and therefore more vulnerability
D. Random selection to avoid bias and surprise adversaries
Correct Answer: A Explanation: CEH methodology emphasizes risk-based prioritization: combine technical exposure (publicly routable services, visible open ports), business impact (critical services that affect revenue or data confidentiality), and technical vulnerability likelihood (observed software versions and known CVEs) into weighted scores to determine testing order. This focuses effort where it matters most. Option B (alphabetical) is arbitrary and not risk-driven. Option C (homepage size) is a poor proxy for risk. Option D (random selection) is not aligned with efficient, impact-focused security assessment practices.

119. A bank customer reports that SMS one-time passcodes for login and funds transfer suddenly stop arriving on their phone. The mobile carrier later confirms the number was “ported” to another SIM after a caller provided the last four of the SSN and billing ZIP. Within hours, the attacker changed the customer’s email and drained the account. Which identity-theft tactic enabled this bypass of SMS-based MFA?
A. Credential stuffing using reused passwords from a breach dump
B. OAuth consent phishing to obtain long-lived API tokens
C. SIM swapping (port-out fraud) to hijack the SMS factor
D. Watering hole attack on a trusted banking blog
Correct Answer: C Explanation: SIM swapping/port-out fraud (C) involves social-engineering the mobile carrier to reassign the victim’s phone number to an attacker-controlled SIM, redirecting SMS OTPs and facilitating account takeover (ATO) even without the password if the attacker also resets it by intercepting verification messages; this is a well-documented MFA bypass and a prime identity theft vector. Credential stuffing (A) explains password reuse but not the loss of SMS OTP delivery; OAuth consent phishing (B) abuses OAuth scopes/tokens but does not require carrier interaction or explain missing SMS; watering hole (D) is web compromise of a third-party site and is unrelated to telephony-based factor hijack.

120. A provider observes a 600+ Gbps volumetric attack consisting of small spoofed UDP requests to exposed servers and extremely large replies sent to the victim. Which service exposure MOST likely enabled such extraordinarily high amplification?
A. DNS ANY queries to open recursive resolvers on 53/udp
B. SSDP (UPnP) responses from consumer devices on 1900/udp
C. NTP “monlist”/mode 6 responses from legacy NTP servers on 123/udp
D. Memcached exposed over UDP on 11211/udp returning large cached values
Correct Answer: D Explanation: Misconfigured memcached over UDP can yield extremely high amplification (tens of thousands of times) when attackers send spoofed requests that elicit very large value responses to the victim; this has been used in some of the largest recorded floods. Option A (DNS ANY) and Option C (NTP monlist) are significant amplifiers but typically with lower factors than memcached and are increasingly mitigated. Option B (SSDP) offers modest amplification compared to memcached and is commonly encountered on consumer gear, but it generally does not reach the same peak magnitudes.

121. Which option best distinguishes a zero-day from other common CEH vulnerability concepts?
A. A weakness introduced by misconfiguration, already fixed upstream but not yet applied locally
B. A previously unknown vulnerability with no vendor patch available at the time of discovery/use
C. An exposure publicly disclosed with an official CVE and vendor mitigation advisory released months ago
D. A weakness that requires social engineering to exploit and therefore is not a software defect
Correct Answer: B Explanation: In CEH, a zero-day is a previously unknown flaw with no patch at time of use/disclosure; attackers may weaponize it before defenders can respond. A is a misconfiguration or a lagging patch scenario (not zero-day). C is an N-day—publicly documented with vendor fixes/mitigations. D conflates exploitation vector (social engineering) with vulnerability class; human vectors do not define zero-days.

122. During a non-blind TCP hijack on a local subnet, the attacker is sniffing both directions of a Telnet session and wants the server to accept injected keystrokes. Which requirement is MOST critical for acceptance of the injected segment?
A. Matching Time-To-Live (TTL) and DSCP bits to the victim’s packets
B. Matching the Maximum Segment Size (MSS) and negotiated window scaling values
C. Using an in-window sequence number with a correct acknowledgment number
D. Preserving TCP option ordering exactly as in the original three-way handshake
Correct Answer: C Explanation: TCP acceptance is governed by the receiver window and sequence/acknowledgment values; the injected segment’s sequence must fall within the receiver’s window and carry a valid ACK relative to the peer’s last sent data. This is the core requirement for successful data injection in active hijacking per TCP state machine behavior (RFC 793 and updates). A is incorrect because TTL/DSCP mismatches may hint at anomalies but do not determine accept/reject. B is not required once the connection is established; hijacking works so long as the attacker respects the effective window regardless of the original MSS/scale. D is also not required for midstream injection; while option quirks can aid fingerprinting, they are not the acceptance predicate for established-flow data segments.

123. During passive discovery you identify devices advertising _hap._tcp (HomeKit), _googlecast._tcp, and multiple hosts responding to SSDP. You suspect a local IoT hub at 192.168.1.50 exposing a REST API. What is the BEST next step in the methodology to enumerate device functionality with minimal risk?
A. Query local service discovery (mDNS/SSDP) and then perform authenticated, read-only API enumeration against the hub, reviewing OpenAPI/Swagger if present
B. Launch a full credential brute force against the hub’s HTTP endpoints to reveal hidden resources
C. Directly fuzz the hub’s POST endpoints with boofuzz to identify memory corruption vulnerabilities
D. MITM all hub traffic by ARP spoofing to harvest tokens and replay API calls automatically
Correct Answer: A Explanation: After passive discovery, the next methodical, low-impact step is controlled enumeration: leverage mDNS/SSDP records to identify endpoints and perform read-only API discovery (e.g., check /openapi.json//swagger.json, OPTIONS/HEAD, and documented GETs) to understand resources, auth mechanisms, and scopes before any intrusive action. B (brute force), C (fuzzing), and D (MITM) are higher-risk/invasive activities reserved for later phases once authorization models, scopes, and safety constraints are understood per CEH methodology.

124. Attackers are exploiting stateless ACLs that treat any packet with the TCP ACK flag set as “established/allowed.” Which firewall configuration change MOST effectively prevents such forged-ACK evasion?
A. Require true stateful TCP inspection (track SYN/SYN-ACK/ACK handshake state) rather than relying on a single-flag stateless rule.
B. Block all TCP ACK packets globally regardless of state.
C. Open all ports to reduce the need for ACK checks.
D. Rely on a strict “deny any” policy with no logging.
Correct Answer: A Explanation: A is correct because stateful inspection ensures that packets are only allowed if the firewall has seen the proper handshake (SYN→SYN-ACK→ACK) and maintains a connection table; this prevents simple forged-ACK bypasses. B would break legitimate established connections. C increases attack surface and is reckless. D (“deny any” without logging) is not a targeted technical fix and removes auditability; the right answer is enable/strengthen stateful inspection and possibly TCP sequence validation.

125. A client requests a list of all subdomains indexed by major search engines and asks you to automate retrieval. Which approach MOST responsibly balances completeness and rate-limit/legal concerns when using search engines?
A. Script automated queries to Google with short intervals between queries to maximize throughput and bypass rate limits
B. Use search engine APIs (e.g., Bing Web Search API) or certified OSINT providers' APIs, respect rate limits, and aggregate results with caching and throttle controls
C. Rely solely on manual, browser-based searches because automation is always blocked and unreliable
D. Use browser automation (Selenium) to simulate human queries and evade API costs while collecting results quickly
Correct Answer: B Explanation: The responsible and scalable approach is to use official search APIs (Bing, Google Custom Search where allowed) or reputable OSINT providers that provide indexed subdomain data, respect their rate limits and terms of service, implement caching, and aggregate results programmatically — this avoids abusive scraping, reduces legal and IP concerns, and produces repeatable, auditable results. Option A (automated queries to Google without regard for rate limits) risks IP blocking and violates terms of service; it’s irresponsible. Option C (manual searches only) is overly laborious and unnecessary when APIs exist. Option D (Selenium to simulate human queries to bypass API costs) is deceptive, likely violates terms of service, and can be legally and ethically problematic.
